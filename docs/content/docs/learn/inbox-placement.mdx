## 投递与收件箱到达的区别 [#delivery-vs-placement]

大多数冷邮件工具报告的是“投递成功率”，即收件方 SMTP 服务器接收的邮件比例。这个数字几乎总是接近 100%，却几乎无法提供有效判断。

接收服务器可以先接收邮件（完成投递），再立即将其过滤到垃圾邮件、推广邮件，或其他不属于收件箱的位置。收件箱到达率指已被接收的邮件中，最终进入收件人主收件箱的比例。

这两个数字可能相差很大。对于身份验证配置不完善的冷邮件邮箱，99% 的投递成功率与 30% 的收件箱到达率同时出现，并不罕见。

## 如何测量投递位置 [#how-placement-is-measured]

### 预热探测 [#warmup-probes]

Warmbly 的[预热池](/learn/warmup-pools/)也用于探测投递位置。池中成员会报告每封预热邮件进入了哪里：收件箱、垃圾邮件或推广邮件。我们按发件邮箱，在滚动样本窗口内汇总这些数据。

探测准确性取决于预热池的多样性。只包含 Gmail 地址的池，无法反映 Outlook 上的投递位置。我们的高级预热池覆盖 Gmail、Outlook、Yahoo、iCloud 和自托管 IMAP 服务器，其比例参照更广泛的收件方分布。

### 种子名单 [#seed-lists]

一些团队会维护“种子名单”：一组分布在不同服务商上的固定邮箱，每次发送营销活动邮件时，都会向这些邮箱发送副本。种子名单中的投递位置可以近似反映整个营销活动的投递位置。

种子名单有用，但并非没有偏差。这些邮箱往往比真实的冷邮件收件邮箱使用时间更长、互动更活跃，应将其视为方向性信号。

Warmbly 的[收件箱到达测试](/guides/placement-tests/)就是这样运行的：从你的某个邮箱，将营销活动中的一个步骤或一份草稿发送到各服务商的种子测试邮箱，再根据 Message-ID 查找每份副本，将其分类为收件箱、Gmail 某个分类标签页、垃圾邮件，或始终未收到。

### 收件人反馈 [#recipient-feedback]

如果收件人将邮件从垃圾邮件移回收件箱、回复邮件，或将你加入通讯录，服务商有时会通过 FBL 数据流或工作区集成告知你。这些是最强的单次互动信号。

## 哪些因素会降低收件箱到达率 [#what-hurts-placement]

- 未通过身份验证的邮件（[SPF、DKIM、DMARC](/learn/spf-dkim-dmarc/) 缺失或未对齐）。
- 原本发送量较低的邮箱突然大量发信。
- 冷邮件使用大量 HTML、附带未经请求的附件，或正文只有跟踪像素。
- 数千封邮件的内容逐字相同，容易被内容特征识别捕捉。
- 指向可疑顶级域名的冗长 URL，或被滥用的 URL 缩短服务。
- 收件人持续不打开就删除邮件。
- 收件人将邮件标记为垃圾邮件，这是最差的信号。

## 哪些因素有助于进入收件箱 [#what-helps-placement]

- 冷邮件序列使用纯文本正文。
- 发送量与该邮箱的历史基线相称。
- 真实收件人的真实回复，这是最强的正向信号。
- 针对不同收件人调整主题和开场句。
- 精简且目标明确的联系人名单。向明显不合适的地址（从网页解析得到的地址、职能邮箱等）发送，会提高退信和投诉风险。
- 稳定的发送模式：每天在相同的工作时段发送，周末暂停。

## 建议目标 [#targets-to-aim-for]

<PlacementScale />

| 收件箱到达率 | 含义 |
| --- | --- |
| 高于 90% | 邮箱健康。 |
| 80–90% | 可以接受，但要注意下滑趋势。 |
| 60–80% | 存在问题，应检查身份验证、内容和发送量。 |
| 低于 60% | 停止使用该邮箱发送营销活动邮件，并立即排查。 |

## 为什么我们不以打开率为核心指标 [#why-we-dont-lead-with-open-rate]

Apple 的邮件隐私保护会代收件人预先获取图片，无论真人是否查看邮件，都会为每封邮件生成一次“虚假”打开。Gmail 会积极缓存图片，根据缓存状态，可能产生重复“打开”记录，也可能完全不记录。

结果是：打开率仪表盘上的数字，与实际阅读之间并无稳定的对应关系。Warmbly 会展示打开情况供特定场景参考，但不会据此作出邮件送达能力方面的决策。

<Callout type="info" title="投递位置是领先指标">
  回复率则是滞后指标。如果收件箱到达率开始下滑，而你只观察回复，往往会晚约三周才发现问题。
</Callout>
