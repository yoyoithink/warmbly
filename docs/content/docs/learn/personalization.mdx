Warmbly 的每个主题行和邮件正文都支持合并变量与简单条件判断。邮件实际发送时，会针对每位收件人分别渲染，因此一份模板也能自然地适用于整份名单。

<ShortVersion>

- `{{.FirstName}}` 等变量会在发送时，按每位收件人的信息填入。
- 缺失值会渲染为空，因此应让周围文字能够适应空值，或使用条件判断保护。
- 条件判断可以让文本只在字段有值，或匹配指定值时出现。

</ShortVersion>

  本页介绍基本概念及组合方式。包含每个字段、辅助函数和规则的完整语法参考，见[表达式指南](/guides/expressions/)。
</Callout>

## 变量 [#variables]

插入变量后，发送时会将其替换为对应联系人的具体信息。标准联系人字段包括 `{{.FirstName}}`、`{{.LastName}}`、`{{.Email}}`、`{{.Company}}` 和 `{{.Phone}}`：

```
Hi {{.FirstName}},

Thanks for the work you're doing at {{.Company}}.
```

如果联系人缺少某个值，该变量不会输出任何内容，也就是留空。编写句子时，应确保空值不会破坏语句，或使用下文介绍的条件判断。

## 自定义字段 [#custom-fields]

联系人上的任何自定义字段也能使用，引用时必须与字段名称完全一致。例如，字段名为 `role` 时：

```
You're the {{.role}} at {{.Company}}, right?
```

名称包含空格或标点的字段（例如 `Job Title`）同样可以通过点号引用。按原始名称准确书写即可在任何位置使用，包括条件判断中：

```
{{if .Job Title}}Role: {{.Job Title}}{{end}}
```

如果你更习惯 `index` 写法，也可以使用等价的 `{{index . "Job Title"}}`。[表达式指南](/guides/expressions/)介绍了这两种形式。

名称必须匹配联系人上实际存在的字段，否则值为空。因此，只要周围文本依赖某个自定义字段，就应配合条件判断使用。

## 条件判断（if / else） [#conditionals-if--else]

用条件语句包裹文本，使其只在字段有值，或匹配某个指定值时显示。

仅在字段有值时显示文本：

```
Hi {{.FirstName}},{{if .Company}} I saw {{.Company}} is hiring.{{end}}
```

Company 有值时，结果为“Hi Alex, I saw Acme is hiring.”；字段为空时，结果为“Hi Alex,”。

<MergePreview />

通过 `else` 提供回退内容：

```
{{if .FirstName}}Hi {{.FirstName}}{{else}}Hi there{{end}},
```

使用 `eq` 匹配指定值：

```
{{if eq .city "Berlin"}}I'll be in Berlin next week.{{else}}Let's set up a call.{{end}}
```

`eq` 按文本精确比较，并且区分大小写：`eq .Company "acme"` 不会匹配“Acme”。

可以使用 `else if` 串联多个选项，也可以使用 `and` / `or` 组合条件：

```
{{if eq .plan "enterprise"}}your team's size{{else if eq .plan "pro"}}your growing team{{else}}teams like yours{{end}}
```

```
{{if and (.FirstName) (eq .Company "Acme")}}Hi {{.FirstName}} at Acme{{end}}
```

缺失或为空的字段视为“未设置”（false）。支持的关键字与运算符完整列表见[表达式指南](/guides/expressions#conditionals)。

## 一个完整的复杂模板 [#a-complete-complex-template]

下面将这些能力组合起来：一份模板中的主题、称呼、按职务调整的开场句、与城市相关的补充内容，以及按套餐调整的行动邀请，都会针对不同收件人变化。除了标准字段，它还使用三个自定义字段（`role`、`city`、`plan`）：

```
Subject: {{if .Company}}quick idea for {{.Company}}{{else}}a quick idea{{end}}

Hi {{if .FirstName}}{{.FirstName}}{{else}}there{{end}},

{{if eq .role "Founder"}}As the founder, you probably feel {{else if eq .role "Marketing"}}On the marketing side, you've likely noticed {{else}}You've probably run into {{end}}the cost of {{if .Company}}{{.Company}}'s{{else}}your{{end}} cold email landing in spam instead of the inbox.

{{if and (.city) (eq .city "Berlin")}}I'm in Berlin next week and happy to grab a coffee. {{end}}We get teams to the inbox with gradual warmup and per-mailbox limits, no gimmicks.

{{if eq .plan "enterprise"}}Given your volume, worth a 15-minute call?{{else if eq .plan "pro"}}Want the 2-line version of how it works?{{else}}Open to a quick look, or not a priority right now?{{end}}

Best,
Sam
```

应逐步完善这些模板，并多使用编辑器的“预览”标签页。它会用示例数据计算条件判断，让你在发送前查看每个分支的结果。

## 回退值 [#fallbacks]

字段可能为空时，可以使用 `default` 设置回退值，而不必编写完整的 `{{if}}` 代码块。先写原值，再写回退值：

```
Hi {{.FirstName | default "there"}},
```

名字有值时，结果为“Hi Alex,”；为空时，结果为“Hi there,”。这是解决常见“Hi ,”问题最简洁的方式。任何字段可能为空的位置，都可以使用 `| default "…"`。

## 函数 [#functions]

一些辅助函数可以调整文本或处理数字，它们可写在任意 `{{ }}` 或条件表达式中：

- 文本：`upper`、`lower`、`title`（转换大小写）、`trim`、`contains`、`hasPrefix`、`hasSuffix`
- 列表：`has`（判断是否包含完整项）、`join`（连接为一行文本）
- 数字：`add`、`sub`、`mul`、`div`、`mod`、`num`，以及会进行类型转换的比较函数 `gtf`、`ltf`、`gef`、`lef`。即使输入值是文本，它们也会按数字处理。

```
{{upper .Company}} team - {{title .role}}
```

```
{{if gtf .score 80}}You're in our top tier.{{end}}
```

提示：只要值可能是文本，就应优先使用 `gtf`/`ltf`，而不是普通的 `gt`/`lt`。它们会先转换类型，避免类型错误。完整辅助函数列表和细节见[表达式指南](/guides/expressions#functions)。

## Spintax：变化表达方式 [#spintax-vary-your-wording]

将几个选项放在花括号内，并用 `|` 分隔，Warmbly 就会为每位收件人随机选择一个。变化措辞可以避免大量邮件看起来像完全相同的群发内容，有助于改善[邮件送达能力](/learn/deliverability/)。

```
{Hi|Hey|Hello} {{.FirstName | default "there"}},

{Hope your week is going well|Hope you're doing well} over at {{.Company}}.
```

只有包含 `|` 的分组才会被处理，因此普通花括号（用于链接、片段或样式）会保持原样。Spintax 在变量渲染之后展开，所以可以自由混用两者。

## 自动化条件：高级表达式 [#automation-conditions-advanced-expressions]

自动化流程的 **IF** 步骤提供**高级表达式**模式，用于编写下拉选项无法表达的逻辑。条件为真时进入“是”分支。可以直接写条件（`gt .confidence 0.8`），也可以使用 `and` / `or` / `not` 组合：

```
and (gtf .confidence 0.8) (eq .intent "positive")
```

引用事件字段时，前面加点号（`.confidence`、`.intent`）；可用变量取决于触发器。操作中的值（例如 Slack 消息、Webhook 请求体或 CRM 字段）与条件一样，基于实际触发数据渲染：数字仍保留数字类型，因此普通 `gt` 即可使用；同时也能使用完整模板功能，包括条件判断、嵌套字段和 `{{range}}`。只有值可能以文本形式传入时，例如联系人自定义字段，才需要使用 `gtf`：

```
{{if gt .confidence 0.8}}hot lead{{else}}follow up{{end}}
```

表达式输入框旁的“参考”按钮会在当前界面列出所有变量和函数；详细说明见[表达式指南](/guides/expressions#automation-advanced-expressions)。

## 出现问题时怎么办 [#if-something-goes-wrong]

Warmbly 会在三个环节防止模板出错：

- 编辑时，如果条件语句不配对（例如有 `{{if}}` 却没有 `{{end}}`），会在当前位置显示警告。
- 只要某个步骤的模板格式错误，营销活动就无法启动。错误会指出具体步骤，避免收件人收到未处理的 `{{if ...}}` 文本。
- 如果错误模板仍进入发送环节，系统会回退到简单的变量替换，而不是让发送失败。

模板也有使用限制，避免单个模板长时间占用服务器。`{{range}}` 只能遍历数据字段（`{{range .items}}`），不能遍历数字或函数结果，且循环最多嵌套两层。不支持 `{{template}}` 和 `{{block}}`。违反这些规则的模板会被视为格式错误；输出超过 1 MB 时，则回退到简单替换。

启动前始终应检查预览，并先向自己发送一封测试邮件。
