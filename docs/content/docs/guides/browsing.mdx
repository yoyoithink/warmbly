---
title: "浏览与筛选"
description: "刷新页面或返回浏览视图时，保留筛选、搜索、排序和视图选择。"
---

Warmbly 会在当前浏览器标签页中记住浏览控件的设置。刷新页面、离开后再次返回，都会恢复上次的选择，而不是悄悄重置列表。

## 会记住哪些设置 [#what-is-remembered]

- 账户、域名和营销活动：搜索、筛选与排序。账户列表还会记住所选标签；详情面板会分别记住各账户或域名上次打开的标签页。
- 联系人、分群和营销活动潜在客户：搜索与筛选条件，按列表或资源分别保存。现有保存的列布局和排序仍然有效。
- CRM：任务筛选及平铺或分组视图、商机表格筛选、看板所选销售管道与搜索，以及会议时间范围与搜索。
- 收件箱：搜索、用户添加的筛选、排序，以及相关侧栏、历史记录和嵌套浏览控件。当前收件箱查看范围仍由导航或 URL 决定。
- 数据分析、送达能力和投递位置：报告时间范围、显示的指标、服务商筛选及相关结果视图。
- 表单、模板、API 密钥、审计和设置历史记录：这些列表提供的搜索、筛选、排序和视图标签页。

各资源的控件设置相互独立。例如，一个联系人的活动筛选不会应用到另一个联系人；更改某个营销活动的潜在客户筛选，也不会影响主联系人列表。

## URL 与重置 [#urls-and-resets]

明确的 URL 或导航操作仍优先于记住的选择。打开指向特定标签或详情标签页的链接，会直接展示目标位置。切换工作区时，会恢复目标工作区的选择，而不会用先前工作区的筛选覆盖它。

使用**清除**、**所有账户**或其他重置控件时，重置后的状态也会被记住。收件箱范围切换保留原有的重置行为：切换范围会清除先前范围的附加筛选和搜索，而**搜索所有邮件**则会有意将搜索内容带入更广的范围。

收件箱的相对日期预设始终相对于当天计算，自定义日期则保持为选定日期。若筛选引用的标签或其他项目不可用，只要列表支持，仍可以移除此筛选；不会仅因相关目录仍在加载就将其悄悄清除。

## 偏好设置的保存位置 [#where-preferences-live]

这些浏览偏好按登录用户、工作区和浏览器标签页保存在本地。无需增加自托管设置、修改数据库或执行数据迁移，也不会随工作区导出。关闭标签页会结束已保存的浏览会话；退出登录或会话过期时，这些浏览偏好会被清除。

刷新会重新加载当前数据，从结果第一页开始，不会恢复批量行选择、已加载的结果页或已打开的编辑器和对话框。此偏好存储机制不改变应用现有的草稿保存行为。

如果浏览器存储被禁止或已满，浏览控件仍可正常使用，但刷新后可能无法保留选择。无效或过时的已保存值会安全回退到该视图的默认值。
