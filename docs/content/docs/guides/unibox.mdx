统一收件箱（Unibox）集中展示所有已连接邮箱。你可以在同一页面阅读、整理和回复邮件，无须逐个登录账户。

![统一收件箱：左侧为文件夹、邮箱和标签，中间为对话列表，右侧为已打开线程](/guides/unibox.webp)

## 回复会话 [#reply-to-a-conversation]

<Steps>

<Step>

从主导航打开**收件箱**。

</Step>

<Step>

在左侧**范围侧栏**选择文件夹、视图或邮箱。

</Step>

<Step>

点击列表中的对话，阅读完整线程。

</Step>

<Step>

在线程内回复。**发件人**默认使用保存该邮件的邮箱。

</Step>

</Steps>

## 使用须知 [#good-to-know]

- 已验证的预热邮件不会进入统一收件箱，也不会增加未读数量。
- 归档和删除也会同步整理 Gmail、Outlook 或 IMAP 邮箱中的对话；删除只会将邮件移入邮箱自身的垃圾箱。
- 收到邮件中的远程图片保持隐藏，直到你点击**加载图片**。
- 立即发送默认等待 30 秒，因此发出前仍可**取消**。
- 无须刷新：新邮件和未读计数会自动更新。

## 收件箱显示的内容 [#what-the-inbox-shows]

浏览筛选、搜索和视图选择会[在浏览器标签页中记住](/guides/browsing/)，刷新或导航后仍保留，并按用户和工作区分别保存。

所有已连接邮箱共用一个收件箱，可在同一页面阅读、整理和回复，无须逐个登录账户。页面分为三栏：选择查看范围的**范围侧栏**、**对话列表**，以及阅读和回复的**线程视图**。

已验证的[预热邮件](/guides/warmup/)不会进入统一收件箱，包括邮箱的已发送副本及 [Warmbly Cloud](/guides/warmbly-cloud/) 运行的预热邮件。它们不会产生收件箱通知、增加未读计数或触发回复分类。消费者还会每天及每次重启后批量检查已有邮件，从统一收件箱移除确认属于预热的邮件，同时移除此前产生的回复通知。服务商邮箱中的邮件仍保留，普通对话不受影响。

## 布局 [#layout]

顶部导航显示工作区和**收件箱**，不显示邮箱、文件夹或邮件标识符。打开某个范围或对话后，点击面包屑中的**收件箱**可返回默认收件箱视图。手机上，页眉保留工作区选择器，隐藏分区面包屑。

各栏宽度可自行调整。本节中的选择会保存在当前浏览器，下次打开时恢复你离开时的布局。

| 控件 | 功能说明 |
| --- | --- |
| 范围侧栏与列表之间的分隔线 | 拖动可调整范围侧栏宽度。聚焦后，方向键可微调（按住 `Shift` 增大步长），`Home` 和 `End` 分别设为最小和最大宽度，`Enter` 或双击恢复默认 220 px。宽度保存在当前浏览器。 |
| 列表与线程之间的分隔线 | 拖动可加宽对话列表，以显示较长主题，也可将空间留给线程。聚焦后同样支持键盘：方向键微调（按住 `Shift` 增大步长），`Home` 和 `End` 调至窗口允许的最窄和最宽，`Enter` 或双击恢复默认。 |
| 左侧导航底部的**折叠**，或 `b` | 将 Warmbly 主导航收起为图标栏，为页面腾出宽度。行名称改为提示文字；未读邮件仍显示计数徽标，未解决的[优化顾问（Advisor）](/guides/advisor/)问题在图标上显示彩色圆点。相同控件可再次展开导航。 |
| 左侧导航中的分区标题（邮件、CRM、资源） | 点击可收起分区，再次点击恢复。与其他布局选择一样，此状态保存在当前浏览器。收起后仍显示当前页面；标题旁的彩色圆点表示隐藏页面中有未解决的[优化顾问（Advisor）](/guides/advisor/)问题。图标栏也遵循相同选择。 |
| 范围侧栏中的分区标题（邮件、视图、邮箱、标签、邮箱标签） | 点击可收起分区，再次点击恢复。收起的分区仍显示当前查看范围；标题旁的小蓝点表示被折叠的某行有高亮计数（主动隐藏的行不会触发）。标题旁的 **…** 或右键菜单可折叠其他全部分区、全部展开，或将分区向上、向下移动。**邮件**和**视图**旁的铅笔可进入行编辑模式：取消勾选以隐藏行，拖动手柄或聚焦手柄后用方向键排序，完成后按**完成**、`Escape`，或点击其他位置。**重置**恢复该分区的初始布局。手机上长按标题或行可打开相同菜单。每行也有自己的 **…** 和右键菜单，可移动、隐藏（支持撤销）或将文件夹标为已读；`Alt` 配合方向键可移动聚焦行。一次只打开一个菜单，打开另一个、点击或轻触其他位置，或按 `Escape` 都会关闭它。铅笔旁的“已隐藏 2 项”等文字提示有行已隐藏。隐藏只影响侧栏显示，快捷键和链接继续可用，当前范围始终保持可见。隐藏项以及行、分区顺序按工作区保存到账户，因此手机和其他已登录浏览器显示相同侧栏；分区折叠状态则按浏览器保存。 |
| 行的 **…** 菜单中的**添加到收藏**，或**邮件**和**视图**编辑模式下行旁的星标 | 将范围固定到侧栏顶部的**收藏**分区，让每天查看的位置集中显示，无论它们原属哪个分区：邮件中的收件箱和已发送、需要回复等视图、单个邮箱、标签或邮箱标签。收藏有内容后才显示该分区，各行也继续保留在原分区，使用相同实时计数。收藏可像其他分区一样折叠、移动和排序（编辑模式下拖动，或 `Alt` 配合方向键）。通过收藏菜单中的**重命名**、聚焦收藏后按 `F2`，或编辑模式下点击其旁的铅笔，可设置独立名称，例如“工作收件箱”，原位置的行仍保留真实名称；清空名称即可恢复。编辑模式下取消勾选，或选择**从收藏中移除**可移除并支持撤销；分区 **…** 菜单中的**移除全部收藏**可清空收藏。当前范围只高亮一次，默认在收藏中高亮，除非你从原分区打开。收藏及名称与侧栏其他排列一样，按工作区保存到你的账户，随你同步到手机和其他浏览器，不与团队成员共享。在侧栏布局改为账户保存之前设置的布局，会在首次打开统一收件箱时接续使用。 |
| 线程标题栏中的联系人按钮 | 显示或隐藏右侧联系人面板。没有已保存偏好时默认关闭。打开或关闭状态跨对话保留，已有偏好不变。 |

列表可用的最大宽度取决于窗口：线程始终保留足够阅读邮件的空间，打开联系人面板时也会计入，因此笔记本上的最大宽度小于大屏显示器。

屏幕宽度小于 1024px 时，联系人面板改为覆盖层而非独立列，因此始终默认关闭。小于 768px 时，列表和线程轮流占满屏幕，不再并排。

联系人面板显示对话另一方，即第一个不属于工作区邮箱的发件人。它先按地址查找联系人。如果该地址不是联系人，但对话是在回复营销活动邮件（对方常会从别名、第二个域名或同事账户回复），面板会显示该活动原先联系的潜在客户，并通过**实际回复地址**说明实际回复地址。只有两者都未匹配时，才提供**添加为联系人**。

## 键盘操作 [#keyboard]

对话列表支持键盘操作，整轮邮件分拣无须鼠标。在 Warmbly 任意位置按 `?` 可查看完整快捷键；以下快捷键用于收件箱。

| 按键 | 作用 |
| --- | --- |
| `j` / `k` | 在列表中向下或向上移动。尚未选择时，无论列表如何排序，`j` 选中第一条对话，`k` 选中最后一条。 |
| `g g` / `G` | 跳到第一条或最后一条对话。 |
| `Enter` | 尚未选择时，打开最上方对话。 |
| `x` | 勾选或取消勾选当前行，以建立选择集。 |
| `e` | 归档选中内容；没有勾选项时归档当前行。 |
| `Escape` | 先清除勾选行，再关闭已打开对话。在搜索框中使用时，将键盘焦点交回列表。 |
| `/` | 将输入光标移到列表搜索框。 |
| `c` | 为已打开对话添加标签。 |

快捷键弹窗只列出当前页面实际可执行的操作，因此这些项目只在收件箱打开时显示。

## 文件夹 [#folders]

侧栏先显示两个简短分组，再显示各邮箱。第一组是日常处理区：**全部邮件**、**收件箱**、**未读**、**等待回复**、**智能体草稿**、**稍后处理**。第二组包含其他邮件文件夹及**计划发送**，便于直观看清收发方向：

| 文件夹 | 分组 | 显示内容 |
| --- | --- | --- |
| 收件箱 | 第一组 | 收到的邮件，以及服务商自定义文件夹中的邮件，除非该文件夹被[排除同步](/guides/mailboxes/#folders-you-do-not-want-synced) |
| 草稿 | 第二组 | 邮箱草稿文件夹中的邮件 |
| 已发送 | 第二组 | 发出的营销活动邮件和手动邮件 |
| 归档 | 第二组 | 已归档邮件（Gmail 的全部邮件，其他服务商的归档文件夹） |
| 垃圾邮件 | 第二组 | 服务商标为垃圾邮件的内容 |
| 垃圾箱 | 第二组 | 已删除 |

**计划发送**位于已发送与归档之间。它是视图而非文件夹，列出工作区所有邮箱排队中的发送，无论由哪位团队成员安排，与已发送放在一起便于理解。

从主导航打开**收件箱**时，默认进入收件箱文件夹。发出的邮件位于**已发送**；如需同时查看收件和发件，选择**全部邮件**。打开收件箱中的对话后，仍会看到包括你的回复在内的完整历史。

每封邮件最初归入服务商所在的文件夹：IMAP 特殊用途文件夹属性、Gmail 标签和 Outlook 已知文件夹都映射到相同六类。服务商侧的移动（归档、删除、标为垃圾邮件、移出垃圾邮件或移回收件箱）会在下次同步跟进。在 Gmail 中，这些操作都是标签变更，Warmbly 根据最终标签归类，因此在 Gmail 归档的对话也会离开此处收件箱。Gmail 邮箱还会每隔数小时重新核对，以捕获实时同步遗漏的移动。草稿同样会协调：邮箱中已不存在的草稿会在此处移除，避免 Gmail 每次自动保存的新副本留下旧草稿。你也可自行整理对话，同步移动邮箱中的邮件，详见[整理对话](#filing-a-conversation)。当前行灰色高亮，右侧蓝色显示未读数；悬停文件夹会显示包含**全部标为已读**的三点菜单，手机上则始终显示在计数右侧。

垃圾邮件和垃圾箱不会出现在其他视图，归档也一样：整理对话会将它移出日常待处理区域，因此不再出现在未读、等待回复、各邮箱、标签和邮箱标签视图中，也不计入未读徽标。它仍保留在**全部邮件**和**归档**文件夹，可在那里重新找到。

<Callout type="info" title="垃圾邮件和垃圾箱从连接时开始同步">
首次连接邮箱时的初始导入覆盖收件箱、已发送、归档和草稿。有意跳过垃圾邮件和垃圾箱的已有内容，避免它们的历史占用本应留给真实对话的导入额度。连接后这两个文件夹会正常接收同步，因此展示连接之后到达的内容，而非之前已有内容。
</Callout>

## 权限范围 [#scopes]

| 视图 | 显示内容 |
| --- | --- |
| 全部邮件 | 所有邮箱的全部对话，包括已归档内容，不含垃圾邮件和垃圾箱 |
| 未读 | 至少有一封未读邮件的对话 |
| 等待回复 | 你最后发信，对方尚未回复 |
| 智能体草稿 | [收件箱智能体](/guides/inbox-agent/)已有回复等待审核的对话 |
| 稍后处理 | 已设为稍后处理的对话 |
| 计划发送 | 工作区邮箱排队中的发送 |

下方是预设**视图**，对应销售管道中常见的处理问题。它们基于[自动收件箱标签](/guides/inbox-tagging/)生成的标签，工作区创建后即存在，无须设置：

| 视图 | 显示内容 |
| --- | --- |
| 需要处理 | 需要人工处理的自动邮件，如付款失败、账户停用、可疑登录、发送限制或服务即将到期 |
| 高意向潜在客户 | 标有有兴趣、会议或价格咨询标签的回复 |
| 需要回复 | 对方最后发信，已两天或更久无人回复 |
| 待跟进 | 你最后发信且未收到答复，或原先有兴趣的线程不再有回应 |
| 已拒绝 | 无兴趣、找错人，或请求退订 |
| 自动邮件 | 非人工撰写的邮件：登录验证码、收据、通知、新闻通讯、退信和自动回复 |

视图按标签筛选，因此对话获得标签后立即进入对应视图，标签移除后随即离开。实例未配置分类器密钥时，只有两个跟进视图会根据已发送邮件日期填充。

**自动邮件**有所不同：机器生成邮件会进入此处，而非收件箱。自动标签判断对话不是人工撰写后，它会离开**收件箱**、未读、各邮箱和邮箱标签视图，也不计入未读徽标，只显示在自动邮件和全部邮件中。分类器不确定的邮件仍留在收件箱。人工回复会让对话立即返回，甚至不必等分类完成。需要你处理的自动邮件，如邮箱订阅付款失败或账户停用，绝不会进入自动邮件：它们留在收件箱并标为**需要处理**，同时在**需要处理**视图中显示未读计数，详见[需要你处理的邮件](/guides/inbox-tagging/#mail-that-needs-your-action)。

视图下方，侧栏列出各邮箱及未读数，以及**标签**和**邮箱标签**。长列表默认只显示前几项，并提供 `Show all`（显示全部）开关及内联筛选。需要按今天、最近一周等时间范围查看时，请使用筛选器的日期范围，而非视图；列表标题显示当前视图及已加载对话数量。

计数由服务器在一次请求中返回，因此始终与行内容一致。当前视图和已打开对话保存在 URL 中（`/app/unibox/unread`），刷新、收藏或分享都会到达相同位置。

搜索（按 `/`）覆盖发件人、收件人、主题和邮件正文，因此姓名、地址或正文中间的短语都能找到对话。输入部分单词即可按前缀匹配，结果随输入逐步缩小，无须等完整单词。引号内短语精确匹配，`OR` 扩大匹配范围，`-word` 排除指定词。

查询包含至少三个连续字母或数字后，开始对参与者执行子串匹配。更短查询仍搜索主题和正文单词，包括前缀。搜索不区分大小写，`%`、`_` 和 `\` 均为普通字面字符，不是参与者通配符。如果搜索无法完成，列表会显示错误，而不会声称没有匹配结果。

搜索限定于当前范围。没有结果时，空状态提供**搜索全部邮件**，扩展到所有文件夹并保留已输入内容。手动切换视图会清空搜索框，避免为一个范围输入的查询悄然筛选下一个范围。

标题旁的筛选按钮打开小面板，可即时按已读状态、日期范围（今天、最近 7 或 30 天，或两个指定日期）、发件人、标签、邮箱或整组邮箱标签，以及排序方式缩小列表。新增条件在搜索框下显示为标签块，点击即可移除。如果视图已固定某项条件，如未读或单个邮箱，就不再重复提供该控件。

## 邮件会话串联 [#threading]

每行代表一个对话，而非单封邮件；包含多封邮件时，发件人旁会显示数量。打开后按顺序展示全部邮件，主题下方显示邮件数和所属邮箱。回复及新来信归入同一线程。列表按 `Today`（今天）、`Yesterday`（昨天）、`This week`（本周）和 `Earlier`（更早）分组。

滚动至列表末尾时会加载更多对话，并保持位置：打开对话，或离开收件箱后返回，都会回到此前所在行，而非列表顶部。

切换文件夹或视图会关闭已打开对话，因为它可能不属于新列表。手动关闭时，宽屏可点击对话标题右侧 **X**，手机可点击上方返回链接（显示来源列表名称），也可按 `Escape`。

线程关联在收发两侧都生效。回复携带指向对话最后一封邮件的 `In-Reply-To` 标头，使收件人将其归入同一线程。如果从保存该对话的 Gmail 邮箱发送，还会携带 Gmail 线程 ID，使其在你的邮箱中也归入原线程。收件人邮件客户端只看标头：线程 ID 在生成它的邮箱之外没有意义，因此[从其他邮箱](#choosing-the-sending-mailbox)发出的回复不会携带该 ID。

<Callout type="info" title="键盘导航">
`j`／`k` 在行之间移动，`Enter` 打开，`Esc` 关闭，`/` 聚焦搜索，`c` 添加标签。按 `?` 查看完整列表。
</Callout>

## 阅读邮件 [#reading-a-message]

打开对话时，最新邮件和所有未读邮件会展开；较旧邮件折叠为预览行，点击标题或预览即可展开。正文按封加载，因此长线程不会一次下载全部邮件。

显示内容保留邮件发出时的样式：段落、换行、列表、表格和内嵌图片均保留，特殊字符和表情也按原样显示，而非实体编码。对话列表仍显示单行预览；预览只是邮件摘要，不是完整邮件。

HTML 邮件在隔离框架中显示，发件人样式不会影响控制台，邮件内容也无法执行代码。链接在新标签页打开且不携带来源信息。已存邮件副本无法读取时，Warmbly 会显示已有预览并说明原因，而不会导致整个对话打不开。

对话使用一个阅读滚动条。调整窗格宽度、加载图片或展开引用历史时，正文会自动调整。宽版新闻通讯会适应窗格，避免右侧被截断；无法换行的布局会缩小以完整显示。主题和操作保持在阅读区上方，回复和转发位于下方。窗格较窄时，即使整个屏幕很宽，整理操作也会收进**更多线程操作**。

Warmbly 会从显示副本（包括引用邮件）中移除自身的打开跟踪像素。无论在收件箱、已发送还是其他视图阅读，都不会记录营销活动打开。实际送达的邮件仍保留像素，用于记录收件人打开。

收到邮件中的远程图片只有你主动请求后才加载。任何发件人都可放入跟踪像素，加载会告知其阅读时间、IP 地址和邮件客户端。引用远程图片、背景或字体的邮件会显示带有**加载图片**的提示条，点击后为该封邮件显示这些内容。邮件自身嵌入的图片立即显示，你自己发出的邮件不受影响。

识别出的引用历史会折叠到**显示引用文本**后，点击可阅读完整链条。完全由引用内容组成的邮件，以及无法明确识别的行内回复保持可见。从已连接邮箱发出的邮件有蓝色左边框和**发出**徽标。

### 邮件详情 [#message-details]

每封展开邮件的收件人行都有详情开关，即发件人姓名下方的 `to`；点击发件人姓名或地址也会打开同一面板。它就地展示邮件信封信息：全部 From、Reply-To、To、Cc 和 Bcc 地址，发送时间及与其不同时的接收时间（均使用你的时区），所属邮箱和文件夹、大小，以及 Message-ID 和 In-Reply-To 标头。点击任意地址或标识符即可复制。回复和转发旁的信息图标也会打开该面板，即使邮件仍处于折叠状态。

## 标签 [#labels]

工作区共用一份标签列表，用于[联系人](/guides/contacts-crm/#labels)、此处对话及[表单](/guides/forms/)，因此 `Interested` 在联系人和对话上含义相同。标签也与团队共享：任何人创建的标签都对所有人可用，一位成员给对话添加的标签也会显示给下一位成员。使用对话标题栏的标签按钮或 `c`：搜索已有标签、勾选适用项，或输入名称后**创建**。一个对话可有多个标签。

已加标签的对话在列表行和标题栏显示彩色标签块，各标签也会在侧栏显示自己的计数，便于一键筛选。你手动添加的标签绝不会被系统改动。[收件箱自动打标签](/guides/inbox-tagging/)只会在其旁边追加自己的标签，绝不移除人工标签。

标签用于标记对话和联系人；邮箱标签标记邮箱本身，可按客户或域名分组账户。两者都能从侧栏筛选，但描述的对象不同。

## 已读状态 [#read-state]

对话中只要有一封邮件未查看，就视为未读，表现为边缘蓝点、加粗文字和蓝色时间。打开后会将其中邮件标为已读并更新计数；也可在行或选择集上使用**标为已读**，无须打开。

**标为未读**只将对话中最新收到的邮件标为未读，并优先选择垃圾邮件和垃圾箱之外的邮件。如果没有收到的邮件，则将最新发出副本标为未读；其他情况下，你自己的发出副本保持已读。草稿绝不会标为未读，按单独邮件 ID 或批量处理文件夹也不会将发出副本和草稿标为未读。从已打开对话执行此操作会关闭对话，因为阅读器会将显示内容标为已读。

已读状态双向同步。到达时已读的邮件会按已读存储；在此阅读对话，也会将邮箱本身的邮件标为已读，因此 Gmail、Outlook 和 IMAP 客户端也不再加粗。**标为未读**反向同步，文件夹上的**全部标为已读**会同步整个批量操作。只同步实际变更：再次打开已读对话不会在服务商处产生操作。

Warmbly 自身副本更新后，由持有该邮箱的工作节点立即转发已读操作，因此控制台不会等待服务商响应。如果邮箱恰好正在节点间迁移，或服务商拒绝，Warmbly 保留你的已读状态，服务商邮箱保留自己的状态，不会重试，因为下一次同步会报告服务商实际状态。

## 整理会话 [#filing-a-conversation]

线程标题栏提供三项整理操作：宽屏显示在邮件上方一行，窄屏收进三点菜单：

| 操作 | 作用 |
| --- | --- |
| 标为未读 | 将最新收到的邮件标为未读；没有收到邮件时使用最新发出副本，并关闭对话 |
| 归档 | 将对话移入归档，使其离开收件箱 |
| 删除 | 将对话移入垃圾箱，使其离开垃圾箱以外的全部视图 |

归档和删除的确认提示均提供**撤销**。打开垃圾箱或归档后，相同标题栏提供**移回收件箱**，因此误整理的对话都可恢复。

### 直接从列表操作，无需打开邮件 [#from-the-list-without-opening-anything]

无须打开对话即可处理。悬停行时，首行右侧显示**归档**及三点菜单；手机上这些控件始终可见。菜单包含**在新标签页打开**、**标为已读／未读**、**稍后处理**、**标签**、**归档**或**移回收件箱**，以及**删除**。右键点击行，或在聚焦行上按菜单键、`Shift` + `F10`，会在点击处打开同一菜单。手机上长按约半秒，会在手指位置打开菜单，不打开对话。在归档和垃圾箱中，这些控件改为提供恢复路径。

对当前打开的对话执行这些操作，会像对话自身按钮一样关闭它，包括**标为未读**，因为打开的对话会被视为已读。

从列表行归档会整理整个对话，而非该行预览的单封邮件，因此对话确实会离开原视图。

### 批量处理 [#working-on-several-at-once]

每行左侧边缘都有复选框，替代未读圆点。悬停行可看到，或点击列表标题中的**选择**一次显示全部复选框，并增加可选中当前已加载所有内容的**全部**框。**全部**旁的 **×** 退出选择模式并取消勾选，适合手机操作；键盘按 `Escape` 同样有效。`x` 勾选当前行，按住 `Shift` 再勾选，会选中当前行与上次勾选行之间的整段。

勾选任意内容后，屏幕底部出现操作栏，显示数量及作用于全部选中项的操作：**标为已读**、**标为未读**、**稍后处理**、**归档**或**移回收件箱**，以及**删除**。每项只发起一次请求，因此整理一整屏与整理一条同样快速。**清除**或 `Escape` 可取消选择；切换视图也会取消，因为原选择对应的行已不再是当前屏幕内容。

右键点击已勾选行，或在手机长按，会打开针对整个选择集的菜单，操作与底栏相同，完成后取消选择。右键点击未勾选行则只作用于该行，已有选择不变。

### 同步整理原邮箱中的邮件 [#filing-in-the-mailbox-too]

与已读状态一样，整理操作也会同步到邮箱本身，因此此处整理的对话在 Gmail、Outlook 或 IMAP 客户端中也会同步整理：

| 此处操作 | Gmail | Outlook | IMAP |
| --- | --- | --- | --- |
| 归档 | 移除 Inbox 标签 | 移入归档 | 移入 Archive 文件夹 |
| 删除 | 移入垃圾箱 | 移入已删除邮件 | 移入 Trash 文件夹 |
| 移回收件箱 | 重新添加 Inbox 标签 | 移入收件箱 | 移入 INBOX |

删除绝不会永久移除邮件，而是移入邮箱自身的垃圾箱。在服务商清空前，可通过撤销、**移回收件箱**或邮件客户端恢复。IMAP 服务器没有 Archive 文件夹时，会像 Apple Mail 和 Outlook 一样创建名为 Archive 的文件夹；没有 Trash 文件夹时，服务器副本保持原位。Outlook 和 IMAP 中，你自己的发出副本留在已发送，与其原生客户端归档对话时的行为一致；Gmail 按整个对话整理，因此发出副本会一起进入垃圾箱或返回收件箱。草稿和预热邮件都不会移动。

Warmbly 自身副本整理完成后，由持有邮箱的工作节点执行移动，因此列表不等待服务商。随后节点报告服务商中各封邮件的位置，使下次同步知道移动来自你的操作，而非服务商。如果邮箱恰好正在节点间迁移，或服务商拒绝，对话在此保持已整理状态，在服务商处保持原位，不会重试。

如果某个邮箱只想在 Warmbly 内整理，可在其设置选项卡关闭**同步归档和删除**，详见[邮箱](/guides/mailboxes/#filing-in-the-mailbox)。之后整理只移动此处对话，下次同步不会撤销：Warmbly 分别记录服务商位置和你整理的位置，只有服务商实际移动邮件时才跟进。因此，无论开关状态如何，在 Gmail 归档或标为垃圾邮件都会同步到 Warmbly，而普通同步轮次不会覆盖本地整理。

</Fold>

## 回复 [#replying]

可回复、转发，或悬停某一封邮件专门回复它。主动操作，或返回具有已保存回复、转发草稿的对话时，编辑器会出现。可应用已保存的**模板**或**插入预约链接**。带 HTML 正文的模板会保留格式，详见[模板与 HTML](#templates-and-html)。

### 选择发件邮箱 [#choosing-the-sending-mailbox]

**发件人**默认是保存邮件的邮箱，因此不修改时，回复的发送方式与此前相同。[共享回复收件箱](/guides/mailboxes/#a-shared-reply-inbox)是例外：如果该邮件回复的是另一邮箱发出、且 Reply-To 指向当前邮箱的邮件，发件人默认改为原发信邮箱，使联系人继续收到自己联系的地址发来的邮件。发件人下方会说明原因，并提供从收件箱自身回复的按钮。邮件也会在发件人姓名旁显示所回复邮件来自哪个邮箱。点击发件人可选择工作区中任意其他活跃邮箱，使用与[写邮件](#composing)相同的可搜索选择器，显示各邮箱当日额度、身份验证健康状态及与收件人的历史。这里没有自动选择，回复始终明确指定邮箱。签名预览随所选邮箱变化。保存邮件的邮箱不再活跃时，编辑器会提示，在选择活跃邮箱前禁用**发送**。

从其他邮箱回复会保留对话主题及 In-Reply-To、References 标头，因此收件人仍在同一对话中看到它。服务商线程属于保存它的邮箱，所以除非所选邮箱已有本对话中的邮件，否则首次跨邮箱回复会在那里创建独立线程，后续从该邮箱回复会继续该线程；收件人的答复会到达该邮箱或其 Reply-To 地址。**发件人**下方会说明，并提供**切回原邮箱**恢复原邮箱。转发没有需要延续的线程，直接从所选邮箱发出。

### 转发 [#forwarding]

**转发**将所选邮件发送给新的人。主题添加 `Fwd:`，收件人初始为空。你输入的是可选附言，也可不写直接转发。收件人依次看到附言、发信邮箱签名（启用签名同步时），以及 `Forwarded message` 区块，其中包含原始 From、Date、Subject、To、Cc 行及原邮件正文，保留格式。Date 行使用发信邮箱时区。

[禁止发送名单](/guides/unsubscribe/#the-suppression-list)不适用于转发，因此可转发到营销活动禁止发送的地址或域名。编辑器在附言下显示待转发邮件；发送前可展开**转发的邮件**检查。原邮件附件不会转发。如果只保存了原邮件预览（线程提示“仅保存了此邮件的预览”），编辑器会说明，转发也只包含预览。转发你自己发出的跟踪邮件时，链接恢复真实目标，使新收件人的点击不计入原始发送。

转发后，无论哪个邮箱发送，它都会作为下一封发出邮件，连同转发区块显示在原对话中。等待发出期间（撤销窗口或计划时间），它列在对话的计划发送中。发信邮箱的已发送文件夹同步后才会显示，该同步将副本归入原对话，不另建第二条。只有 Warmbly 这样归类：收件人收到普通转发，创建独立对话，不带指向原对话的 In-Reply-To 或 References；之后在原对话回复，仍回答对方最后一封邮件，绝不会回复该转发。

### 暂停对方的跟进邮件 [#pausing-their-follow-ups]

联系人面板列出发件人作为潜在客户参与的全部营销活动，显示状态和下一步：下个步骤及时间、暂停及解除时间，或流程结束原因。仍有待发送步骤的活动提供**暂停**，打开与活动潜在客户列表相同的对话框，可暂停到指定日期或手动恢复，并附加备注。已暂停者显示**恢复**；如果联系人因[被抄送到另一位潜在客户的邮件](/guides/campaigns/#copying-colleagues-on-one-lead)而暂停，会先询问确认，因为恢复将向其启动第二条线程。流程已结束的潜在客户不显示这两个操作，二者都需要**管理营销活动**权限。参见[外出自动回复与暂停单个潜在客户](/guides/campaigns/#out-of-office-and-pausing-one-lead)。

回复编辑器也可在你答复时执行相同操作。收件人仍有后续跟进排队时，**定时发送**旁的**暂停跟进**可暂停 3 天、1 周、2 周、30 天，或直到手动恢复。如果联系人参与多个此类活动，菜单会逐一列出并默认全选，可取消希望继续运行的活动，至少保留一个。只有回复被接受后才会暂停，发送失败不会暂停任何内容。定时回复会立即暂停跟进，并从实际发送时刻计算暂停时长，防止跟进先于回复发出。撤销或取消回复不会解除暂停；改变主意时，请在联系人面板使用**恢复**。如果潜在客户已因其他原因暂停，例如你写作期间收到外出自动回复，则保留原暂停。

### 回复草稿 [#reply-drafts]

回复和转发会在短暂停止输入后保存；关闭编辑器、离开对话或重新加载时，也会保存最新修改。返回线程会重新打开已保存草稿，包括针对较旧邮件的草稿，并保留所选邮箱和 HTML 正文（如有）。**舍弃**会删除草稿；成功排队发送也会删除。撤销发送会恢复邮件以供编辑，仍使用原邮箱。

这些回复草稿仅属于当前浏览器中已登录的用户和工作区，不会同步到其他设备，不会出现在邮箱的**草稿**文件夹，也不随[工作区导出](/guides/workspace-export-import/)迁移。清除浏览器数据会删除它们。**草稿已保存**表示浏览器存储成功；**草稿未保存**表示离开前应先复制文本。

### AI 草稿 [#ai-drafts]

AI 功能位于光标处。正文聚焦时，点击星光图标或按 **⌘J**，可选择三种操作：在当前位置写作、**根据此线程起草回复**或**继续写作**。

线程草稿以完整对话、联系人记录、营销活动参与情况，以及工作区的**语气风格档案**为依据。读取的是邮件正文而非预览，去除引用历史，并给最近邮件分配最多上下文空间，使草稿回答实际问题，而不只回应开头一句。生成时，审核栏提供**保留**、**重试**、**调整**（例如输入“短一些”进行调整）或**舍弃**。只有按下发送才会发出。每次生成草稿消耗[AI 积分](/guides/ai-credits/)。

选中文本后会出现悬浮的**用 AI 编辑**按钮，可选快速操作（改进、缩短、扩写、修正语法、更友好、更正式）或输入自由指令。只改写选中内容，并提供一键**撤销**和**再试一次**。每次改写消耗一积分。营销活动步骤编辑器也支持相同控件。

编辑会遵循指令，其余内容保持不变：不会把段落重写成一封全新邮件，“修正语法”也只修改语法。个性化标记、条件、spintax、AI 区块、表单链接和普通链接（包括目标）均原样保留，因此改写不会丢失 `{{.FirstName}}` 或退订链接。选中区域内的粗体、斜体和标题样式不会保留，需要样式时请避开这些区域选取。模型判断段落已符合要求时，审核行显示**无更改**，不会声称进行了不可见的改写。

在 **设置 > 工作区** 设置语气风格档案：销售什么、面向谁，以及希望采用什么语气。所有 AI 写作功能都会参考它。

如需自动为每次来信回复起草，并等待批准，请启用[收件箱智能体](/guides/inbox-agent/)。它绝不会自行发送。

## 撰写邮件 [#composing]

点击对话列表顶部的**写邮件**、在任意位置按 `n`，或使用联系人上的**发送邮件**操作，都会打开停靠写信窗口，让你边写边浏览。

窗口标题栏提供**全屏**，将同一个编辑器移到屏幕中央，配以暗色背景，便于长篇写作。再次点击按钮、点击背景或按 **Escape**，会将窗口放回角落，草稿保持不变。再次按 **Escape** 会关闭窗口，并照常保存到草稿。**最小化**始终停靠到右下角。

**收件人**会随输入搜索联系人，也接受直接输入地址。属于禁止发送名单的收件人（退信、投诉、退订或列入禁止域名）会在开始写作前被标出，并阻止发送。

Cc 和 Bcc 旁的**种子邮箱**可将工作区自有[种子邮箱](/guides/placement-tests/#your-own-seed-inboxes)加入收件人，便于手动快速查看邮件落入何处。可逐个勾选、一次选择某个服务商，或全选；选择器会在当前浏览器记住上次选择。工作区至少有一个种子邮箱且你拥有**查看营销活动**权限时才显示。此功能发送一封邮件给所有选中种子，因此各种子都能看到其他收件人。如需每个种子收到独立副本并自动读取结果，请对选定种子运行[投递位置测试](/guides/placement-tests/#choosing-which-of-your-seeds-get-a-copy)。

### 自动选择邮箱 [#auto-mailbox-selection]

**发件人**默认为**自动**，针对收件人为当前工作区每个活跃邮箱评分：优先选择与其已有对话的邮箱，让联系人持续收到同一地址的邮件；其次选择每日剩余额度最多的邮箱，相同时用域名身份验证健康状态决定。

发送前，选择器会显示选中的邮箱及原因。展开后可查看各邮箱的额度条（今日已发送与上限）、历史徽标和身份验证健康圆点，便于判断是否覆盖选择。菜单可按邮箱标签筛选；选择标签后，自动模式仅在该组内选择，对应 `POST /unibox/compose` 的 `from_tag_id` 字段。

### 模板与 HTML [#templates-and-html]

两个编辑器中的**模板**都可从**模板**插入已保存模板。正文为空时直接成为正文，否则附在已写内容下方；模板主题仅在主题栏为空时填入，回复中则仅在主题只有 `Re:` 或 `Fwd:` 时填入。选择器会标出带 HTML 正文的模板。

带 HTML 正文的模板（模板上的**同时发送 HTML 正文**）会将编辑器切换到 HTML，收件人收到原样 HTML，包括文字背后的链接。模板纯文本正文会同时作为纯文本部分发送，因此需要两种版本时应都填写。仅有 HTML 正文的模板会自动生成纯文本部分，并在各链接文字后附上地址。

HTML 模式下，正文使用与邮箱签名相同的编辑器：**HTML**编辑格式化内容，也可通过代码按钮编辑源码；**预览**展示邮件客户端呈现效果；**纯文本**保存纯文本部分。开启**同步 HTML 和纯文本**后，纯文本跟随 HTML，**纯文本**用于预览，实际发送版本在发信时由 HTML 生成。模板自带纯文本时，同步默认关闭。发送时仍会添加邮箱签名。操作栏中的 **HTML** 可将纯文本邮件切换为 HTML，也可在确认后切回纯文本，并将纯文本部分保留为正文。AI 写作仅支持纯文本，因此 HTML 模式不可用；切换为 HTML 或插入 HTML 模板前，必须先保留或舍弃 AI 草稿。

### 草稿与历史记录 [#drafts-and-history]

停止输入片刻后会自动保存到**草稿**，包括 HTML 正文。关闭窗口保留草稿，发送或清空内容则移除。草稿位于收件箱左侧栏顶部，可在任意设备继续编辑，属于个人，不与他人共享。

设置收件人后，**历史记录**会展开与你和对方之间的全部对话：选项卡区分完整线程和仅已发送邮件，搜索可按主题缩小范围，点击行打开真实线程，面板还会提示你通常使用的邮箱。

此处同样支持 **⌘J**、**用 AI 编辑**，以及主题为空时的**建议**操作。AI 草稿依据联系人记录、与该地址的完整往来和语气风格档案生成，审核卡片会显示所用依据。如果确实无法判断邮件目的，它会询问一个简短问题，而不会虚构推销内容。

### 发送控制 [#sending-controls]

| 控件 | 行为 |
|---------|----------|
| **撤销发送** | 立即发送默认等待 30 秒，可在设置 > 个人资料中调整为 5 至 120 秒。标题栏倒计时提供**取消**，将完整邮件返回编辑器。也适用于带 `send_mode: instant` 的 API 发送。 |
| **定时发送** | 将发送安排到稍后。它会在线程中显示为虚线卡片，并进入**计划发送**视图；工作区内任何拥有统一收件箱访问权限的人都可取消。接近工作区排队发送上限时，用量指示器会警告。 |
| **稍后处理** | 将对话暂时移出待处理范围，直到选定时间，最多 90 天后，可使用预设或自定义时间。**立即取消稍后处理**可立即恢复。 |

定时发送和智能排队发送本身已有等待，因此跳过撤销窗口。可从**计划发送**视图或通过 `DELETE /unibox/scheduled/:task_id` 取消。

统一收件箱中的回复、转发和新邮件属于日常对话，不计入邮箱每日营销活动限额或预热发送量。因此，当天营销邮件额度用完的邮箱仍可回复潜在客户。这些操作改受公平使用限制，按收件人数计量，To、Cc 和 Bcc 中的每个地址都计入。

每个邮箱的每日额度设在服务商允许量之下：

| 邮箱 | 24 小时内的收件人数 |
|---------|------------------------|
| Google Workspace 或 Microsoft 365 | 1,500 |
| 其他 IMAP／SMTP 主机 | 750 |
| 个人 Gmail（gmail.com） | 400 |
| 个人 Outlook（outlook.com、hotmail.com、live.com） | 250 |

Warmbly 掌握的邮箱情况可能降低该额度：

- 连接不足 2 天：四分之一；不足 14 天：一半
- 预热中被限流：一半；被隔离或封禁：四分之一
- 工作区受限制：四分之一

无论如何下调，每个邮箱每天至少保留 50 位收件人额度，使对话可以继续。一天内还适用以下限制：

- 任意一小时最多使用每日额度的五分之一，防止突发发送耗尽全天额度
- 单封邮件最多 100 位收件人；若每小时额度更低，则以其为准。更长的收件人列表应使用营销活动
- 用于开启新对话的邮件最多占每日额度的四分之一。对话内回复和转发不计入这一部分，确保邮箱可持续答复

套餐还会对工作区全部邮箱合计设置第二层额度：任意 24 小时内，为套餐每日邮件限额的两倍，且不少于 100。免费试用每日 20 封对应统一收件箱 100 位收件人，Starter 的 150 封对应 300 位，Grow 的 3,000 封对应 6,000 位。每日限额获准提升后，此额度也会提高。没有每日限额的套餐不设工作区额度；未启用计费的自托管实例也不设。

邮箱处于暂停、重新连接、发送问题后的暂缓，或服务商限额后的冷却状态时，统一收件箱同样无法发送。

新邮件或回复的目标地址直接或通过域名命中[禁止发送名单](/guides/unsubscribe/#the-suppression-list)时，会在排队前被拒绝，并明确显示地址及匹配条目。转发不受此限制：它把已收到的邮件传给你手动选择的人，因此可将潜在客户邮件转发给其域名被排除在营销活动之外的客户或同事。转发收件人仍计入公平使用额度。

因上述原因拒绝时，邮件不会发出，邮箱所有者会看到原因及触及的限制，便于稍后或换用邮箱发送。如果 Warmbly 无法确认邮件是否已到达发信工作节点，错误会明确说明；再次发送前请检查**已发送**。

## 实时更新 [#realtime]

无须刷新。新邮件会自动出现在列表、更新已打开线程并增加未读数。对话内容变化后，打开的对话立即更新；侧栏计数、列表和分析在几秒内跟进，使一批来信只触发一次刷新，而非逐封刷新。导航和浏览器标签页中的 **统一收件箱（Unibox）** 计数，是其默认打开的 **收件箱** 视图中未读对话的数量，因此不会指向该视图看不到的邮件：已发送、草稿、已归档、稍后处理和自动邮件对话均不计入。已读状态变化、回复、计划发送、稍后处理和标签变化都会刷新受影响视图，使侧栏计数、列表和已打开线程保持一致。

<Callout type="info" title="保持收件箱健康">
及时回复有助于发件信誉，预热和良好的送达实践也用于维护该信誉。参见[邮件送达能力](/guides/deliverability/)。
</Callout>
