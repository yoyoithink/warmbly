Warmbly 使用你拥有的邮箱发送冷邮件。它会为邮箱预热，将营销活动分散到多个邮箱发送，并把所有回复汇集到同一个收件箱。

## 产品导览 [#the-product-tour]

首次打开控制台时，无论你是自行注册，还是通过邀请加入工作区，都会先看到整个产品的功能导览。导览按章节介绍邮箱、营销活动、联系人、收件箱、数据分析、CRM、自动化流程、[Remie](/guides/ai-assistant/) 和 [Slack](/guides/slack/)，最后介绍套餐：各套餐包含的内容、每日发送量、AI 积分和隔离发送方面的区别，以及可直接选择的套餐卡片。已有套餐的工作区会显示当前套餐，所有者也可从同一组卡片升级或切换。未启用账单功能的自托管实例已开放所有功能，因此卡片会链接到 warmbly.com 上的托管套餐，并在旁边提供通过 [Warmbly Cloud](/guides/warmbly-cloud/) 让实例邮箱加入托管预热池的方式。在手机或较窄窗口中，章节会横排在顶部，可以左右滑动切换页面。每页都会突出显示对应功能在侧边栏中的位置，并用示例数据展示效果。Remie 会沿途讲解，每页还会给出一条可以交给 Remie 执行的请求，代替你逐步点击操作。

- 点击角落的**跳过导览**、章节列表下的**跳过导览**，或按 `Escape`，都可以在任意一页结束导览。首次跳过时会先展示一次套餐；尚未选择套餐的工作区，其所有者可直接从卡片选购。再次跳过，或选择**稍后再说**，即可关闭导览。方向键可切换页面，点击章节列表中的任意章节即可直接进入。
- 完成或跳过的状态会保存到你的账户，因此换设备后也不会再次自动打开。随时可以从侧边栏底部的个人资料菜单中选择**体验导览**重新播放。
- 导览不会修改工作区中的任何内容，其中的数据都是示例。

## 设置工作区 [#set-up-your-workspace]

<Steps>

<Step>

### 连接邮箱 [#connect-your-mailboxes]

打开**账户**，选择**添加账户**。可以连接 Google Workspace、Microsoft 365，或任何支持 SMTP 和 IMAP 的服务商。

![添加账户：Google、Microsoft、任意 SMTP 和 IMAP 服务商、文件导入或邮箱供应商](/guides/add-account.webp)

[了解更多邮箱功能](/guides/mailboxes/)

</Step>

<Step>

### 检查域名 [#check-your-domains]

**发信域名**会显示每个发信域名是否已发布 SPF、DKIM 和 DMARC 记录。

![发信域名：显示每个域名的邮箱、身份验证状态和跟踪主机](/guides/sending-domains.webp)

[了解更多发信域名功能](/guides/sending-domains/)

</Step>

<Step>

### 开启预热 [#turn-on-warmup]

新邮箱默认关闭预热，可以从邮箱的**预热**标签页启用。所有付费套餐都包含预热。

![邮箱的预热标签页：参与状态、今日发送量与递增目标、池内状态，以及递增设置](/guides/mailbox-warmup.webp)

[了解更多预热功能](/guides/warmup/)

</Step>

<Step>

### 发送营销活动邮件 [#send-a-campaign]

打开**营销活动**，选择**新建营销活动**，编写邮件、添加联系人并选择发送时段。

![步骤画布：首封邮件及在同一会话中回复的跟进邮件，每条连接线上显示对应等待时间](/guides/campaign-steps.webp)

[了解更多营销活动功能](/guides/campaigns/)

</Step>

<Step>

### 处理收到的回复 [#answer-the-replies]

所有邮箱收到的回复都会进入**收件箱**。启用[收件箱标签](/guides/inbox-tagging/)后，回复还会根据对方的意图自动标注。

![统一收件箱：左侧为文件夹、邮箱和标签，中间为会话列表，右侧为已打开的会话](/guides/unibox.webp)

[了解更多收件箱功能](/guides/unibox/)

</Step>

</Steps>
