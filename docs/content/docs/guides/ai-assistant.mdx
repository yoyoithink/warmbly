Remie 是 Warmbly 的 AI 助手，以控制台聊天面板的形式提供服务，可以读取整个工作区中的信息，并执行几乎所有你自己能执行的操作。它会在修改任何内容前请求确认，除非具有**管理设置**权限的成员已为该类操作选择**始终允许**。

## 使用须知 [#good-to-know]

- Remie 需要付费套餐，以及角色中的**使用 AI**权限。
- 它以你的身份操作：仅在你的工作区中执行你的角色允许的操作。
- 发送消息、启动会触发发送的功能，以及改变访问权限，始终需要确认，即使已启用**始终允许**。
- 会话默认仅对你可见，除非管理员启用**共享历史记录**。
- 每个步骤消耗一个 AI 积分，可以随时点击停止按钮结束运行。

## Remie 的作用与使用权限 [#what-remie-is-and-who-can-use-it]

Remie 是 Warmbly 的 AI 助手，以控制台聊天面板的形式读取联系人、营销活动、邮箱、统一收件箱、CRM、团队和设置，并执行几乎所有你自己能执行的操作。回答会逐字流式显示，每个工具步骤也会在开始执行时出现。

点击顶部栏中的蓝色圆团，或按 `Cmd/Ctrl + I` 打开 Remie。切换页面时，面板会随你保留。

在 Slack 中提及 `@Warmbly` 或向它发送消息，同一个助手也会回答。参见 [Slack](/guides/slack/#the-assistant)。

<Callout type="info" title="能力范围与限制">
Remie 以你的身份操作：只能在你的工作区内执行你的角色允许的操作，绝不访问其他组织的数据。每次修改都会先询问。**发送消息、启动会触发发送的功能，以及改变访问权限，绝不会自动批准**，即使已启用“始终允许”。
</Callout>

Remie 需要付费套餐；免费试用不包含积分额度，AI 功能也保持锁定。此外，还需要角色中的**使用 AI**权限（管理员和运营者默认启用，查看者默认关闭）；没有该权限时，Remie 和 AI 草拟功能都会隐藏。管理员可以按天、周或月限制每位成员的支出。参见 [AI 积分](/guides/ai-credits/)和[团队与角色](/guides/team-roles/)。

## 会话与侧边面板 [#conversations-and-the-panel]

会话**默认仅对你可见**。管理员可以在“设置 > 工作区 > Remie”中启用**共享历史记录**，此后每位拥有“使用 AI”权限的成员都能看到、打开、继续和删除任何会话，并查看会话所属成员。启用后，已有会话也会公开给这些成员，因此应慎重决定。可以在历史记录栏中逐个删除，也可以通过**清空历史记录**删除你拥有的全部会话。

查看同事的会话时，如果其中某个工具超出你的角色权限，其结果会对你隐藏；你继续该会话时，Remie 也不会获得这些结果。你只能看到执行过某个步骤，看不到返回内容。任何会话都不会保存密钥等机密值：邀请令牌或 Webhook 签名密钥只会在生成它的控制台步骤中，向提出请求的成员显示一次。Remie 自身无法看到，Slack 也不会显示。

会话以标签页形式运行：点击 **+** 可以打开多个会话；阅读其他标签页时，正在运行的会话仍会在自己的标签页中持续输出。展开面板后会显示完整工作区域，并提供按天分组、可搜索的历史记录。

停靠时，可以拖动面板内侧边缘调整宽度；该边缘获得焦点后，也支持键盘操作：方向键微调（按住 `Shift` 可增大步幅），`Home` 和 `End` 分别调整至窗口允许的最窄和最宽，`Enter` 或双击可恢复默认宽度。在桌面端，Remie 以浮动窗口打开，可拖动标题栏移动，并从任意边缘调整大小；位置和大小会被记住。使用停靠按钮或 `Alt + P` 可以将窗口停靠在屏幕任一侧；用同样方式，或将标题栏拖离边缘，可恢复浮动。

| 快捷键 | 操作 |
|----------|--------|
| `Ctrl/Cmd + ]` / `[` | 切换标签页 |
| `Alt + N` / `Alt + W` | 新建聊天 / 关闭标签页 |
| `Alt + M` | 最小化 |
| `?` | 查看所有快捷键 |

**关闭面板不会中断工作。** 最小化后，面板会停靠为状态栏，显示实时状态：正在工作及已运行时长、等待批准，或有未读回复。完全关闭面板也不会停止运行，顶部栏中的圆团会显示状态：工作时旋转，等待审批时变为琥珀色，完成时闪烁绿色，有未读回复时显示圆点。

## 建议与提示 [#suggestions-and-tips]

Remie 会读取[优化顾问](/guides/advisor/)在工作区中检测到的情况，并提出针对性的修复建议，而非泛泛的提示词。空会话会在**为你推荐**下列出这些建议，每类问题一行，例如“3 个新邮箱正在满量发送”。选择一项，就会让 Remie 着手修复：先检查当前状态，再提出最小必要修改，并首先以审批卡片逐项展示。

Remie 偶尔也会在顶部栏圆团下方的小气泡中提供一条建议，并显示**通过 Remie 修复**和**暂不处理**。提示刻意控制在较低频率，以保持其参考价值：

- 只提示优化顾问评为**需要关注**或**严重**的问题。
- 每天最多两次，至少间隔 30 分钟，刚进入页面时不会立即弹出。
- 只在你暂停操作时出现：输入或滚动时不出现，有对话框打开时不出现，Remie 面板打开时也绝不出现。
- 每类问题只提示一次，除非情况恶化；优先提示当前页面的问题。
- 连续关闭两次后，三天内不再提示；气泡中的铃铛可以暂停提示一周。

这些偏好仅属于你个人，按工作区保存在浏览器中。

## 可以让 Remie 做什么 [#what-you-can-ask-remie]

- 查找、读取、创建和删除联系人，修改字段、标签、订阅状态和备注，并进行批量编辑。
- 读取联系人的活动时间线，以及你向其发送过的邮件。
- 列出营销活动和统计数据，并按状态列出潜在客户，以此找出互动冷却的潜在客户。
- 创建、编辑或删除营销活动，管理发件邮箱和跟踪域名，读取日志，编辑邮件序列步骤。
- 启动或停止营销活动（始终询问）。
- 读取分析数据、列出邮箱，并管理具体邮箱：发送上限、预热、跟踪域名、预热封禁申诉和断开连接。
- 读取统一收件箱、起草回复，或发送回复及新邮件（每次发送都会显示完整邮件并询问）。
- 暂缓处理会话、设置标签、标记已读、取消排队中的发送。
- 管理完整的 CRM 流程：商机、任务、备注、销售管道和阶段。
- 读取和管理自动化流程，包括启用流程。
- 管理团队、工作区与表达风格设置、套餐与限额、API 密钥和 Webhook。
- 列出已连接的集成，提供连接入口，并配置 [Slack](/guides/slack/)：通知频道、收件箱频道，以及助手在哪些位置回答。
- 搜索网络并读取公开页面。

它知道你当前所在的页面，因此能正确理解“总结这个营销活动”和“在这里起草回复”等指令。

当可用工具数超过 OpenAI 兼容服务商的 128 个工具限制时，Remie 会按需发现所需工具，包括已连接 MCP 服务器提供的工具，不会删减任何获准使用的能力。发现工具属于只读步骤；实际操作仍遵循正常的权限和审批要求。与其他模型步骤一样，工具发现会计入本次运行的步骤额度，并消耗 AI 积分。

## 操作审批 [#approvals]

**读取操作自动执行。** **修改操作始终先询问** ，审批卡片会显示操作及 Remie 传入的每个参数（展开 **全部参数** 即可查看）。你可以 **批准** 这一次操作，或 **跳过** 。拥有 **管理设置** 权限的成员还可以选择 **始终允许** ，之后整个工作区中的这类操作都无需再询问；其他成员只能逐次批准。

以下操作始终需要询问，也不会提供**始终允许**选项：

- 发送回复或新邮件，以及进行投递位置测试。
- 启动或停止营销活动、启用自动化流程、启动预热、解除邮箱或潜在客户的暂停发送限制，以及向营销活动添加潜在客户，因为这些操作都会推动邮件发送。
- 邀请成员、修改成员角色，以及创建或编辑 API 密钥。

邀请成员、修改成员角色以及轮换 Webhook 签名密钥，还需要与在“设置”中执行时相同的近期身份确认：如果过去五分钟内未确认过本人身份，Remie 会暂停，并要求你先在控制台确认。在 Slack 中遇到这些操作时，请到控制台完成。
- 来自[已连接 MCP 服务器](/guides/connect-mcp-tools/)的工具。

发送审批卡片会显示发件邮箱、收件人、主题，以及纯文本和 HTML 正文。最终发送的只能是这封确切的邮件，由该邮箱发给该收件人。如果你批准回复前，会话中又收到新消息，系统会拒绝原回复，并让 Remie 重新询问。系统也会拒绝向禁止发送名单中的地址发信。

每次审批只决定一项具体操作。如果卡片已不再等待决定（例如已在另一个标签页或 Slack 中处理），再次批准不会产生任何效果。

“设置 > 工作区 > Remie”会列出所有已设为始终允许的操作，以及批准者和批准时间。拥有“管理设置”权限的成员可以**撤销**某项许可，此后该操作会恢复逐次询问。

**草稿始终保留为草稿。** Remie 创建的营销活动不会自动启动，自动化流程也保持禁用；界面会提供按钮，让你在实际编辑器中打开它们。Remie 撰写的文案以工作区的[表达风格档案](/guides/unibox/)为依据，并遵守与 Warmbly 其他功能相同的自然写作规则。

## 积分与隐私 [#credits-and-privacy]

每个步骤消耗一个 AI 积分，每次请求还有固定的步骤上限（运行过程中会显示），防止无限执行。剩余积分显示在面板底部，停止按钮可随时结束运行。自托管安装使用免费或本地模型时，运行不扣积分，并显示“免费模型”提示。

Remie 所做的修改（例如创建任务、更新联系人）会与其他编辑一样出现在共享活动动态中，让同事看到最新状态。

</Fold>
