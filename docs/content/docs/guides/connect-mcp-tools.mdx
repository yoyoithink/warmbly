---
title: "连接 MCP 工具"
description: "连接外部 MCP 服务器，审查其提供的工具并启用，为 Remie 增加能力。"
---

除了 Warmbly 内置工具，AI 助手 Remie 还可以使用你连接的外部 [MCP](https://modelcontextprotocol.io) 服务器提供的工具。连接自有或第三方服务器，审查其工具并启用后，Remie 即可调用这些工具，每次调用前都会征求你的确认。

连接位于**设置、连接**，需要**管理设置**权限。

## 连接服务器 [#connecting-a-server]

点击**添加服务器**并提供：

- **名称**：连接的显示名称，同时也是 Remie 中每个工具名称的一部分。
- **服务器 URL**：指向支持 Streamable HTTP 的 MCP 端点的 `https` URL。仅允许公开的 https URL，内部或私有地址会被拒绝。
- **身份验证**：选择**无**或 **Bearer 令牌**。Bearer 令牌使用工作区密钥加密保存，此后不会再次显示，也不会通过 API 返回。

连接时，Warmbly 会访问服务器，执行 MCP 握手并列出服务器提供的工具。连接初始处于**禁用**状态，在你审查工具之前，不会将其提供给 Remie。

## 审查与启用 [#reviewing-and-enabling]

每台已连接服务器都会显示 Warmbly 发现的工具。阅读工具说明，确认无误后打开开关以启用服务器。只有已启用服务器的工具才会提供给 Remie。

若无法访问服务器，连接位置会显示错误，而不是工具列表。修正 URL 或令牌后，点击刷新图标重新发现工具。刷新也会获取服务器新增加的工具。

## Remie 如何使用外部工具 [#how-remie-uses-external-tools]

外部工具的行为与 Warmbly 自身的写入操作相似，但有一个重要区别：**始终需要审批**。即使设置管理员对内置操作选择了“始终允许”，Remie 也不能自动运行外部工具。每次外部工具调用都会展示将执行的内容，并等待你批准。

Remie 会用连接名称为工具划分命名空间，因此始终能够明确辨认工具所属的服务器。

## 移除连接 [#removing-a-connection]

可随时从服务器卡片断开连接。其工具会立即从 Remie 中移除，已保存的凭据也会被删除。

<Callout type="warn" title="仅连接可信的服务器">
已启用的 MCP 服务器工具由 Remie 代表使用它的成员运行。请仅连接可信的服务器，并优先使用限定权限范围的令牌。外部工具调用始终需要你批准，因此任何操作都会先展示，再执行。
</Callout>
