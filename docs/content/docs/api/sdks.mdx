Warmbly 提供适用于 JavaScript 和 TypeScript、Python 及 Go 的官方 SDK，均具有完整类型支持。每个 SDK 都封装同一组接口：REST API、OAuth2 授权流程和实时网关。它们提供强类型资源、自动分页、自动重试和实时事件流，无需手动编写 HTTP 调用。三个 SDK 均为开源项目，并与 `v1` API 保持同步。

## 快速入门 [#quickstart]

在控制台的“设置”中创建 API 密钥，将其设为环境变量 `WARMBLY_API_KEY`，然后执行：

<Tabs defaultValue="javascript">

<TabsList>
  <LangTab lang="javascript" />
  <LangTab lang="python" />
  <LangTab lang="go" />
</TabsList>

<Tab value="javascript">

```ts
import { Warmbly } from "warmbly";

const warmbly = new Warmbly({ apiKey: process.env.WARMBLY_API_KEY });

// List campaigns (auto-paginated)
for await (const campaign of await warmbly.campaigns.list()) {
  console.log(campaign.id, campaign.name);
}
```

</Tab>

<Tab value="python">

```python
import os
from warmbly import Warmbly

client = Warmbly(api_key=os.environ["WARMBLY_API_KEY"])

for key in client.api_keys.list():
    print(key.name, key.status)
```

`Warmbly()` 会自行从环境中读取 `WARMBLY_API_KEY`；每个方法在 `AsyncWarmbly` 中都有对应的可等待异步版本。

</Tab>

<Tab value="go">

```go
package main

import (
	"context"
	"fmt"
	"log"

	"github.com/warmbly/warmbly-go"
)

func main() {
	client, err := warmbly.New(warmbly.WithAPIKey("wmbly_..."))
	if err != nil {
		log.Fatal(err)
	}

	ctx := context.Background()
	page, err := client.Campaigns.List(ctx, nil)
	if err != nil {
		log.Fatal(err)
	}
	for campaign, err := range page.All(ctx) {
		if err != nil {
			log.Fatal(err)
		}
		fmt.Println(campaign.Name)
	}
}
```

</Tab>

</Tabs>

## 身份验证 [#authentication]

所有 SDK 均接受 Bearer 凭据，两种凭据都受同一套权限检查约束：

- 供自己的脚本使用的 **API 密钥**（前缀为 `wmbly_`）
- 供代表工作区执行操作的应用使用的 **OAuth 访问令牌**（前缀为 `wmat_`）

```ts
// warmbly-js
new Warmbly({ apiKey: "wmbly_..." });       // API key
new Warmbly({ accessToken: "wmat_..." });   // OAuth access token
```

```python
# warmbly-py (falls back to WARMBLY_API_KEY when omitted; any bearer token works)
Warmbly(api_key="wmbly_...")
```

```go
// warmbly-go
warmbly.New(warmbly.WithAPIKey("wmbly_..."))
warmbly.New(warmbly.WithAccessToken("..."))
```

完整的授权码流程和客户端凭据流程（包括 PKCE 和自动刷新令牌）见 [OAuth](/api/oauth/)。密钥格式、权限范围及轮换说明见[身份验证](/api/authentication/)。

## 各 SDK 的共同能力 [#what-every-sdk-gives-you]

- 覆盖整个 API 的强类型 REST 资源，包括邮箱、营销活动、联系人、统一收件箱、分析数据、模板、CRM、集成和 Webhook。
- 内置 OAuth2 流程：带 PKCE 的授权码流程和客户端凭据流程，以及通过编程方式管理 OAuth 应用的功能。
- 通过一条具备故障恢复能力的 WebSocket 连接使用实时网关，支持心跳、自动重连和会话恢复，并推送强类型事件。请参阅[实时服务](/api/realtime/)。
- 默认提供故障恢复机制：使用指数退避和随机抖动自动重试，支持 `Retry-After`，并通过幂等键安全地重试修改操作。
- 游标分页配合自动分页迭代器，让你无需自行跟踪游标即可遍历所有记录。
- 强类型错误包含 `request_id` 和可供程序识别的错误码，可与具名错误标识进行匹配。请参阅[错误码](/api/error-codes/)。
- 体积精简：warmbly-js 和 warmbly-go 均无运行时依赖。
