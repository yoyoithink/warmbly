这些端点覆盖 Warmbly 的集成层：服务商目录和连接生命周期、每个连接的事件订阅与字段映射、可视化自动化流程构建器、已预约会议列表，以及按需 Google Sheets 潜在客户同步。多数读取操作可供集成功能使用者访问（`use_integrations` / `INTEGRATIONS`），而连接和配置属于设置操作，需要 `manage_settings`。

集成是付费套餐功能。浏览目录和列出连接对所有组织开放，未付费组织可看到升级提示；但组织没有付费套餐时，任何修改调用，包括连接、授权、配置、推送、测试和自动化流程写入，都会返回 `403`，消息为“集成功能仅适用于付费套餐”。

本组列表多数采用各自的封装，例如 `{"connections": [...]}`、`{"automations": [...]}`，而非其他位置使用的游标分页 `data` + `pagination` 结构。会议搜索和潜在客户同步来源列表为例外，具体见各处说明。错误采用标准 `{error, message, code, request_id}` 封装，参阅[错误码](/api/error-codes/)。

## 列出集成目录 [#list-the-integration-catalog]

`GET /integrations/catalog`

返回 Warmbly 支持的每个服务商的静态元数据，并标明各 OAuth 服务商是否已配置服务端凭据（`configured`）。

身份验证：**权限范围** `INTEGRATIONS`，或具有**组织权限** `manage_settings` 或 `use_integrations` 的会话。

### 响应 [#response]

`catalog` 数组，包含服务商条目。

```json
{
  "catalog": [
    {
      "provider": "hubspot",
      "name": "HubSpot",
      "tagline": "Sync contacts and deals to your CRM",
      "category": "crm",
      "auth_method": "oauth",
      "beta": false,
      "highlights": ["Push contacts on demand", "Auto-sync on positive reply"],
      "scopes": ["crm.objects.contacts.write"],
      "events": ["email.replied", "meeting.booked"],
      "action_types": ["hubspot.upsert_contact"],
      "supports_push": true,
      "configured": true,
      "rank": 1
    }
    // ... one entry per provider
  ]
}
```

`rank` 表示服务商在本实例的使用排名，`1` 为使用最多。排名依据具有有效连接的工作区数量；并列时按预设顺序决定，因此新实例也有排名。数组本身保持目录顺序；按 `rank` 排序可将使用最多的放在前面。

## 列出社区应用 [#list-community-apps]

`GET /integrations/community`

返回发现页面显示的[社区目录](/guides/integrations/#community-apps)条目：精选应用优先，其后是已在发布者以外至少 25 个工作区安装、且这些工作区各自已创建至少两周的已发布应用，按安装数从多到少排序。仅可通过链接访问的应用不会在此返回。

身份验证：**权限范围** `INTEGRATIONS`，或具有**组织权限** `manage_settings` 或 `use_integrations` 的会话。

| --- | --- | --- | --- |
| `limit` | query | integer | 范围 1 至 200，默认 100。超出范围返回 `400`。 |
| `cursor` | query | string | 来自 `pagination.next_cursor` 的不透明游标。不是由本 API 签发的游标返回 `400`。 |

`status` 为 `featured` 或 `published`，`listed` 表示是否在发现页面展示。`developer` 是发布工作区的名称。`installs` 统计本实例中持有有效授权的工作区数，`installed` 表示调用者工作区是否有任何人持有有效授权。绝不包含凭据、重定向 URI 或 Webhook 设置。

## 创建连接 [#create-a-connection]

`POST /integrations/connections`

为采用 `api_key` / `webhook` 的服务商，例如 Close 或 Discord，创建基于凭据的连接。OAuth 服务商在此会被拒绝，并提示改为启动授权流程（`POST /integrations/oauth/start`，仅限会话）。

身份验证：**权限范围** `INTEGRATIONS` · **组织权限** `manage_settings`。

### 请求体 [#request-body]

| 字段 | 类型 | 必填 | 说明 |
|-------|------|----------|-------------|
| `provider` | string | 是 | 有效的服务商 ID，例如 `close`、`discord`。 |
| `label` | string | 否 | 显示在连接卡片上的友好名称。 |
| `config` | object | 否 | 服务商专用配置，例如粘贴的 API 密钥或 Webhook URL。 |

```json
{
  "provider": "close",
  "label": "Close (Outbound)",
  "config": { "api_key": "api_xxx" }
}
```

### 响应 [#response-3]

`201 Created`，直接返回创建的 `IntegrationConnection` 对象，无额外封装。对于入站服务商 Calendly 和 Cal.com，响应会包含仅显示一次的 `inbound_webhook_url`。

```json
{
  "id": "c0ffee00-0000-4000-8000-000000000abc",
  "provider": "close",
  "label": "Close (Outbound)",
  "status": "connected",
  "auth_method": "api_key",
  "sync_direction": "push",
  "health": "unknown",
  "created_at": "2026-06-11T10:00:00Z",
  "updated_at": "2026-06-11T10:00:00Z"
}
```

## 替换字段映射 [#replace-field-mappings]

`PUT /integrations/connections/:id/field-mappings`

整体替换某个对象在连接中的默认字段映射。完整替换本身具有幂等性，因此无需 `Idempotency-Key` 也可安全重试。

身份验证：**权限范围** `INTEGRATIONS` · **组织权限** `manage_settings`。

| 参数 | 位置 | 类型 | 说明 |
|-----------|-----|------|-------------|
| `id` | path | uuid | 连接 ID。 |

### 请求体 [#request-body-3]

| 字段 | 类型 | 必填 | 说明 |
|-------|------|----------|-------------|
| `object` | string | 否 | 映射适用的服务商对象，例如 `contact`。 |
| `mappings` | array | 是 | 要保存的完整映射集合，替换所有现有映射。 |
| `mappings[].external_field` | string | 是 | 服务商侧目标字段，每条映射必填。 |
| `mappings[].warmbly_field` | string | 有条件必填 | 来源 Warmbly 字段。除非 `transform` 为 `static`，否则必填。 |
| `mappings[].transform` | string | 否 | 取值为 ``（无）、`none`、`static`、`uppercase`、`lowercase`、`trim` 之一。 |
| `mappings[].static_value` | string | 有条件必填 | `transform` 为 `static` 时必填。 |

```json
{
  "object": "contact",
  "mappings": [
    { "warmbly_field": "email", "external_field": "email", "transform": "" },
    { "warmbly_field": "first_name", "external_field": "firstname", "transform": "trim" },
    { "external_field": "lifecyclestage", "transform": "static", "static_value": "lead" }
  ]
}
```

### 响应 [#response-11]

替换后的完整映射集合，结构与列表端点相同。

```json
{
  "mappings": [
    {
      "id": "44444444-4444-4444-8444-444444444444",
      "connection_id": "9b2c1f7e-4d6a-4f2b-bb11-9d0e2a7c5f33",
      "object_name": "contact",
      "warmbly_field": "email",
      "external_field": "email",
      "transform": "",
      "is_default": true,
      "created_at": "2026-06-11T12:30:00Z"
    }
  ]
}
```

## 将联系人推送到 CRM [#push-contacts-to-a-crm]

`POST /integrations/connections/:id/push`

将指定的组织联系人同步插入或更新到已连接的 CRM，包括 HubSpot、Pipedrive、Salesforce、Close。重试本身安全：各服务商的插入或更新均以邮件地址为键，重复推送会收敛到相同结果，不会产生重复记录，无需 `Idempotency-Key`。响应返回逐条结果。对于 Salesforce，每个联系人会匹配对应的 Lead 或 Contact；不存在时按连接的 **Create as（创建类型）** 设置创建，并通过其[字段规则](/guides/salesforce/#field-mapping)更新。

身份验证：**权限范围** `INTEGRATIONS` · **组织权限** `use_integrations`。

| 参数 | 位置 | 类型 | 说明 |

## Salesforce 同步 [#salesforce-sync]

| 方法 | 路径 | 组织权限 | 用途 |
|--------|------|----------------|---------|
| GET | `/integrations/salesforce/:id/overview` | 读取 | 健康状况、API 用量和额度、发件队列计数、上次拉取。`?checks=1` 还会探测连接用户可创建和编辑的内容 |
| GET | `/integrations/salesforce/:id/settings` | 读取 | `{ settings, warmbly_fields, defaults }` |
| PUT | `/integrations/salesforce/:id/settings` | `manage_settings` | 替换设置。整体写入文档，因此重试会收敛到相同状态 |
| GET | `/integrations/salesforce/:id/metadata` | 读取 | Lead 和 Contact 字段、Lead Status 和 Lead Source 选项列表 |
| GET | `/integrations/salesforce/:id/users?q=` | 读取 | 有效 Salesforce 用户，用于负责人选择器 |
| GET | `/integrations/salesforce/:id/list-views?object=Lead\|Contact` | 读取 | 连接用户可见的列表视图 |
| GET | `/integrations/salesforce/:id/campaigns?q=` | 读取 | Salesforce Campaigns（营销活动） |
| POST | `/integrations/salesforce/:id/import/preview` | `use_integrations` | 输入 `{ source_kind, object, source_id }`，返回 `{ total, sample }`，不写入任何内容 |
| GET | `/integrations/salesforce/:id/import-sources` | 读取 | 已保存的导入及其最近结果 |
| POST | `/integrations/salesforce/:id/import-sources` | `manage_settings` | 保存导入，并启动首次运行 |
| PATCH | `/integrations/salesforce/:id/import-sources/:sourceId` | `manage_settings` | 编辑名称、`campaign_id`（`null` 可清除）、`category_ids`、`recurring`、`enabled` |
| POST | `/integrations/salesforce/:id/import-sources/:sourceId/run` | `use_integrations` | 立即运行。已有运行时返回 `409 import_running` |
| DELETE | `/integrations/salesforce/:id/import-sources/:sourceId` | `manage_settings` | 移除导入。已导入的联系人保留 |
| GET | `/integrations/salesforce/:id/activity?status=&contact_id=&cursor=&limit=` | 读取 | 活动日志，最新优先，结构为 `{ data, pagination }` |

| POST | `/integrations/salesforce/:id/sync-now` | `use_integrations` | 立即记录待处理活动，并拉取变更 |
| GET | `/contacts/:id/salesforce` | `view_contacts` | 联系人的 Salesforce 卡片：关联记录、负责人、状态、商机、近期 Tasks、同步状态 |

“读取”权限可为 `manage_settings` 或 `use_integrations`。API 密钥需要 `INTEGRATIONS` 权限，但 `GET /contacts/:id/salesforce` 例外：它显示商机，需要 `READ_CRM`。

## 创建自动化流程 [#create-an-automation]

`POST /automations`

| `trigger_event` | string | 是 | 触发流程的事件，例如 `email.replied`。 |

}

## 创建潜在客户同步来源 [#create-a-lead-sync-source]

`POST /lead-sync/sources`

保存新的按需同步来源，将某个 Google Sheets 工作表绑定到 Warmbly 联系人导入器。

身份验证：**权限范围** `WRITE_CONTACTS` · **组织权限** `manage_contacts`。

### 请求体 [#request-body-11]

| 字段 | 类型 | 必填 | 说明 |
|-------|------|----------|-------------|
| `connection_id` | uuid | 是 | 组织的 `google_sheets` OAuth 连接。 |
| `sheet_id` | string | 是 | Google 电子表格 ID。 |
| `sheet_title` | string | 否 | 电子表格标题，用于显示。 |
| `tab_title` | string | 否 | 要读取的工作表标签。 |
| `has_header` | boolean | 否 | 第一行是否为表头。 |
| `column_mapping` | array | 是 | 列到目标的映射（[与联系人导入结构相同](/api/reference/contacts/)）。保存时即验证，不等到下次同步；映射没有 `email` 列，或自定义字段名称不符合 Warmbly 要求时，此处返回 `400`。 |
| `dedup` | string | 否 | 冲突策略：`skip`、`update` 或 `create_duplicate`。 |
| `target_campaign_id` | uuid | 否 | 每次同步时，将新增或更新的潜在客户加入此营销活动。 |
| `category_ids` | string[] | 否 | 添加到已同步潜在客户的标签 ID。 |
| `segment_ids` | string[] | 否 | 每次运行时，每条同步记录都以手动纳入覆盖规则固定加入的分群。每个 ID 都必须属于组织内的分群，否则保存返回 `400`；若分群之后被删除，则运行时忽略该分群，不使整次运行失败。 |
| `subscribed_default` | boolean | 否 | 新联系人默认订阅状态。 |
| `label` | string | 否 | 友好名称。 |

```json
{
  "connection_id": "88888888-8888-4888-8888-888888888888",
  "sheet_id": "1AbCdEfGhIjKlMnOpQrStUvWxYz",

  "target_campaign_id": null,
  "category_ids": [],
  "segment_ids": [],
  "subscribed_default": true,
  "label": "Q2 inbound leads"
}
```

身份验证：**权限范围** `WRITE_CONTACTS` · **组织权限** `manage_contacts`。

| 参数 | 位置 | 类型 | 说明 |
|-----------|-----|------|-------------|

### 请求体 [#request-body-12]

| 字段 | 类型 | 必填 | 说明 |

| `sheet_id` | string | 否 | 新的电子表格 ID。 |
| `sheet_title` | string | 否 | 新标题。 |
| `tab_title` | string | 否 | 新的工作表标签。 |
| `has_header` | boolean | 否 | 是否有表头的开关。 |
